# Office 表格模板工具

新增入口：顶部工具栏 `Office 表格`

这个工具保留原 `表格` 工具不变，作为第二个使用层存在。

## 定位

- 原 `表格`：AI 驱动，适合从杂乱资料中理解字段、补全文案、智能映射。
- 新 `Office 表格`：非 AI 驱动，适合模板字段确定、批量套用、合规预检、快速导出。

## 当前能力

- 导入 `xlsx / xls / csv` 源数据
- 支持 `{{sku}}`、`{{price}}`、`{{country}}` 等模板占位符
- 可上传自定义 Excel 模板
- 不上传模板时使用内置模板：
  - 商品详情页
  - 采购单
  - 报价单
  - 发票
  - 装箱单
  - 邮件回复
- 右侧实时 HTML 预览
- 批量套用字段
- 导出批量结果为 `xlsx`
- 本地设置层：
  - 默认市场
  - 日期格式
  - 默认模板
  - 必填字段
  - 禁用词
  - 字段别名

## OfficeCLI 对应关系

- `merge` 思路：本地把模板中的 `{{field}}` 替换为表格行数据
- `view html` 思路：右侧把当前模板结果渲染为 HTML 预览
- `validate` 思路：导出前检查必填字段、禁用词、标题长度、单位本地化
- `batch` 思路：源表格每一行生成一个结果 sheet

## 后续可升级

当前版本在浏览器内执行，方便先验证产品结构。

如果后续接入真正 OfficeCLI，可以把前端生成的任务参数交给 n8n 或本地服务：

```json
{
  "tool": "office-excel",
  "action": "merge",
  "docType": "product",
  "template": "uploaded-template.xlsx",
  "rows": [],
  "settings": {}
}
```

前端使用层和设置层可以保持不变，只替换执行层。
